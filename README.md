**Ask Azeroth anything – experienced players answer.**

New to World of Warcraft Forever? Ask your question in game and players who
know the answer reply in a thread. There's no website and no external tool:
questions and answers go from player to player over hidden addon channels,
one per language. AskAzeroth is in development; there is no release yet.

## Supported versions

| Client | Interface |
| --- | --- |
| WoW: Forever | 16001 |

Classic Era, retail and other clients are not supported.

## Installation

AskAzeroth isn't released yet. Once it is:

1. Install it with the CurseForge or Wago app, or download the zip from
   [GitHub releases](https://github.com/PhenomDevel/AskAzeroth/releases/latest).
2. Manual install: extract `AskAzeroth` into
   `World of Warcraft/<client>/Interface/AddOns/`.
3. Log in and type `/aa`.

What changed: [CHANGELOG.md](https://github.com/PhenomDevel/AskAzeroth/blob/main/CHANGELOG.md)

## Features

Planned for the first release:

- **Ask a question** with a category (quest, class, dungeon, profession,
  interface, other), a short summary and optional details.
- **Threads:** every question can get any number of answers; mark it as
  solved when you're happy.
- **Mentor mode** for experienced players, with notifications per category
  that pause in combat and in instances.
- **Your own player list:** favourites, ignored players, notes and a
  "helped me" counter, all kept on your computer only.
- **My questions** with your answers, kept as long as you like.
- **Pin answers:** pin any helpful answer, also on other players' questions.
  It's kept on your computer together with the question and never expires.
- **Built-in FAQ** in English and German.
- **7 languages:** English, Deutsch, Français, Español, Italiano, Русский,
  Português.
